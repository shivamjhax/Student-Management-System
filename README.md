# Student Management System (C)

This is a simple Student Management System made using C programming. I built this project to practise C concepts and understand how student records can be managed through a computer program.

## About the Project

The program allows users to add student details, view records, search for a student, update information and delete records. It also has options to sort students by marks, find the class topper and calculate the average marks.

Student information is stored in a text file, so the records can be accessed again when the program is reopened.

## Features

- Add new student records
- View all students
- Search student by ID
- Update student details
- Delete student records
- Sort students according to marks
- Find the class topper
- Calculate average marks
- Save and load records using file handling
- Basic input validation

## Technologies Used

- C Programming Language
- GCC Compiler
- Structures
- Functions
- Arrays
- Pointers
- File Handling

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/shivamjhax/Student-Management-System.git
```

**2. Open the project folder**

```bash
cd Student-Management-System
```

**3. Compile the program**

```bash
gcc main.c -o student
```

**4. Run the program**

Windows:
```bash
student.exe
```
